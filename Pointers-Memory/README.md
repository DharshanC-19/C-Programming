# Level 3 – Pointers and Memory Management

This level focuses on understanding pointers, memory handling, structures, unions, and dynamic memory allocation in C programming.

## Topics Covered

- Swapping values using pointers
- Accessing arrays using pointers
- String length using pointers
- Modifying values using pointer functions
- Structures and student records
- Sensor readings using structures
- Structure versus union
- Dynamic memory allocation using malloc() and free()

## Learning Outcome

- Developed a better understanding of pointers and memory addresses.
- Practised pointer arithmetic and pointer-based functions.
- Learned to create and access structures and unions.
- Understood the difference between structure and union memory allocation.
- Practised dynamic memory allocation and deallocation.
- Improved understanding of memory management in C.
