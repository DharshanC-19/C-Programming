# Level 2 – Logic, Arrays & Functions

This level focuses on developing C programming skills through logical problem-solving, arrays, loops, functions, and string handling.

## Topics Covered

- Prime number checking
- Fibonacci series
- Number reversal
- Arrays and calculations
- Minimum and maximum in arrays
- Linear search
- Bubble sort
- String length calculation
- Functions and modular programming
