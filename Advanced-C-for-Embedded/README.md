# Level 4 – Advanced C for Embedded

This level focuses on advanced C programming concepts used in embedded systems, including bit manipulation, macros, storage classes, type qualifiers, and modular programming using header files.

## Topics Covered

- Setting a particular bit
- Clearing a particular bit
- Toggling a particular bit
- Checking whether a bit is set
- Extracting specific bits
- Bit manipulation using macros
- Static and extern keywords
- Const and volatile qualifiers
- Creating custom header files
- Include guards and modular programming
- Compiling and linking multiple source files

## Learning Outcome

- Developed an understanding of bitwise operations and bit manipulation.
- Learned to create and use bit masks for individual bit operations.
- Practised writing reusable macros.
- Understood static storage duration and external linkage.
- Learned the purpose of const and volatile in embedded programming.
- Practised creating custom header files and separating declarations from implementations.
- Gained experience compiling and linking multiple C source files.
- Improved understanding of modular programming for reusable embedded drivers.
