# Level 5 – Embedded C Applications

This level focuses on applying C programming concepts to embedded-style applications through software simulations. It introduces firmware concepts such as GPIO control, LED operations, finite state machines, software timers, circular buffers, UART communication and sensor data processing.

## Topics Covered

- GPIO ON/OFF simulation
- LED blinking logic
- Traffic light controller using finite state machines
- Button and LED control simulation
- Software timer implementation
- Circular buffer implementation
- UART character transmission
- UART string transmission
- UART character and string reception
- Sensor data processing using structures
- Sensor reading average calculation
- Threshold checking and status monitoring
- Structures, arrays, pointers and functions

## Learning Outcome

- Understood basic GPIO and LED control logic through software simulation.
- Learned to model finite state machines using enumerations and switch-case.
- Practised button input and LED state management.
- Understood counter-based software timers and event flags.
- Implemented circular buffer operations with full and empty condition checks.
- Practised UART character and string transmission and reception simulations.
- Learned to process multiple sensor readings using structures and arrays.
- Implemented average calculation and threshold-based NORMAL/ALERT status checking.
- Improved the ability to organize embedded-style programs using functions and modular logic.
