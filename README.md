# C Programming for Embedded Systems

This repository documents my learning journey in C programming, starting from fundamental concepts and progressing towards advanced C programming and embedded-style applications.

It contains 45 practice exercises organized into five levels, focusing on logical problem-solving, memory management, bit manipulation and firmware-oriented programming concepts.

## Learning Roadmap

| Level | Title | Topics Covered |
|---|---|---|
| Level 1 | C Programming Basics | Variables, data types, operators, conditions and loops |
| Level 2 | Logic, Arrays & Functions | Problem-solving, arrays, strings, searching, sorting and functions |
| Level 3 | Pointers and Memory Management | Pointers, structures, unions and dynamic memory allocation |
| Level 4 | Advanced C for Embedded | Bit manipulation, macros, static, extern, const, volatile and header files |
| Level 5 | Embedded C Applications | GPIO simulation, state machines, timers, circular buffers, UART and sensor data processing |

This repository is part of my preparation for a career in Embedded Systems and Firmware Development.

Through these 45 exercises, I have progressively developed my C programming knowledge, from basic programming fundamentals to embedded-style application development.

The embedded application exercises are software simulations developed using C and GCC. They provide a foundation for applying these concepts to microcontrollers such as STM32.
