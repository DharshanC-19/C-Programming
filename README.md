# C Programming for Embedded Systems

This repository documents my learning journey in C programming, starting from the fundamentals and progressing towards advanced concepts used in embedded systems development.

The practice programs are organized into different levels, with each level focusing on specific programming concepts through hands-on exercises.

## Learning Roadmap

| Level | Title | Topics Covered |
|---|---|---|
| Level 1 | C Programming Basics | Variables, data types, operators, conditions, loops |
| Level 2 | Logic, Arrays & Functions | Problem-solving, arrays, searching, sorting, functions |
| Level 3 | Pointers and Memory Management | Pointers, structures, unions, dynamic memory allocation |
| Level 4 | Advanced C for Embedded | Bit manipulation, macros, static, extern, const, volatile, header files |
| Level 5 | Embedded C Programming | Embedded programming concepts and hardware-oriented C practice |

## Skills Practised

- C programming fundamentals
- Logical problem-solving
- Arrays, strings and functions
- Pointers and memory management
- Structures and unions
- Bitwise operations and bit manipulation
- Preprocessor directives and macros
- Storage classes and type qualifiers
- Header files and modular programming
- Compilation and linking multiple source files

## Tools Used

- **Programming Language:** C

## Learning Objectives

- Build strong fundamentals in C programming.
- Improve logical thinking and problem-solving skills.
